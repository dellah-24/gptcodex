# ZWConnect

The reorganized ZWConnect v21 production package is available in two forms:

- [`downloads/ZWConnect-v21-reorganized.zip`](downloads/ZWConnect-v21-reorganized.zip) — complete downloadable ZIP
- [`zwconnect-v21/`](zwconnect-v21/) — browsable source code

The package contains the public marketplace, customer account and cart routes,
owner and worker workspaces, inventory, purchasing, administration, courier
portal, PWA assets, Supabase schema, database migrations and Edge Function.

See [`zwconnect-v21/PACKAGE_NOTES.md`](zwconnect-v21/PACKAGE_NOTES.md) and
[`zwconnect-v21/docs/ARCHITECTURE.md`](zwconnect-v21/docs/ARCHITECTURE.md) for
deployment and architecture details.
